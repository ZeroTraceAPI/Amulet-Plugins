# Amulet-Plugins (Community-Maintained Fork)

An independent community-maintained fork of [PREMIEREHELL/Amulet-Plugins](https://github.com/PREMIEREHELL/Amulet-Plugins), focused on keeping the plugins functional and available through bug fixes, compatibility improvements, and ongoing maintenance.

Maintenance primarily focuses on **Multi Tools**. Other included utilities and older versions may receive less frequent updates.

This fork preserves credit to the original maintainer and contributors. It is not an official upstream project, but improvements remain available for possible upstream reuse if the original maintainer returns.

## Original Project

- [Original Repository](https://github.com/PREMIEREHELL/Amulet-Plugins)
- [Original Demonstration Video](https://youtu.be/6siUoN8_9zg)

## Usage and Safety

**Back up your Minecraft worlds before making changes**, especially when using experimental tools or tools that modify or delete world data.

## Availability, Contact, and Contributing

The plugins in this community-maintained fork are available free of charge, with no required payment or paywall.

The maintained source for this fork is the [ZeroTraceAPI Amulet-Plugins repository](https://github.com/ZeroTraceAPI/Amulet-Plugins). When sharing, forking, modifying, packaging, or redistributing these plugins, please link back to this repository so users can find a current maintained copy. Preserve credit to the original maintainer and contributors, along with applicable license notices.

Contributions are welcome. Use [GitHub Issues](https://github.com/ZeroTraceAPI/Amulet-Plugins/issues) for public questions, bug reports, feature requests, compatibility reports, and testing notes when possible.

If you do not want to create a GitHub account, contact the maintainer at:

`ZeroTraceAPI@proton.me`

Include the affected plugin or tool and its version, Amulet version, Minecraft edition and version, operating system, and a clear description when relevant.

Maintenance and support are provided on a best-effort basis and are not guaranteed.
